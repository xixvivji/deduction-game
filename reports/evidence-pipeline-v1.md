# AI 근거 파이프라인 전후 실측

2026-10-21, 로컬 Ollama qwen3:4b-instruct. 원자료: [evidence-pipeline-v1.json](evidence-pipeline-v1.json).

같은 8개 합성 투표 상황을 각 2회, 조건별 16회 실행했다. 전은 전체 문맥+기존 ID/형식 검증, 후는 MCP 검색+구조화 주장 검증+제한 재검색이다. 여러 변경을 함께 비교하므로 MCP 또는 RAG 단독 효과로 해석하지 않는다. 조건 순서를 번갈아 실행하고 최초 워밍업과 MCP 시작 시간은 본 지연시간에서 제외했다. 캐시 영향은 남을 수 있다.

| 측정 | 전 | 후 |
|---|---:|---:|
| 정답 | 10/16 (62.5%) | 11/16 (68.75%) |
| 평균 지연 | 4.65초 | 7.13초 |
| p95 지연 (16건의 최댓값) | 6.29초 | 16.53초 |
| 입력 토큰 합계 | 45,862 | 42,568 |
| 출력 토큰 합계 | 1,624 | 3,267 |
| 평균 생성 시도 | 1.00 | 1.4375 |
| 재검색 합계 | 0 | 7 |
| 검증 실패 후 기본 행동 | 0 | 3 |
| 필요한 근거의 초기 문맥 포함률 | 100% | 100% |
| 권한 밖 검색 기록 ID | 0 | 0 |

정답 기준은 확정 근거가 있을 때 해당 대상 투표, 없을 때 기권이라는 보수적 정책이다. 게임에서 허용되는 의심 기반 투표도 이 기준에서는 오답일 수 있다. 공격 목격 상황은 양쪽 모두 2회 실패했다. 개선 후에도 오답 5건이 남아 있으며 정확도 증가 1건을 일반적인 추리 능력 향상으로 단정할 수 없다.

입력 토큰은 약 7.2% 줄었지만 재생성으로 출력 토큰과 지연이 증가했다. 평균 지연은 약 53.2% 증가했다. 실제 청구 비용은 측정하지 않았으며 로컬 모델 토큰 수를 금전 비용으로 환산하지 않았다. 근거 포함률은 고정 보존 기록을 포함하므로 벡터 Recall@k나 검색 정밀도가 아니다. 권한 밖 ID가 없었다는 결과는 자유 발언의 모든 정보 누출을 검사했다는 뜻이 아니다.

이는 작은 고정 합성 세트이며 독립 holdout, 장기 승률, 사용자 만족도 평가가 아니다. 평가 시 재검색 실패 후 기권도 정답으로 채점될 수 있으므로 정답률과 fallback 수를 함께 제시한다.
