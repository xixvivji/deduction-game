## 발견 사항과 수정

실제 발언에서 '의견: 의견:' 접두사 중복을 발견했다. 모델이 이미 붙인 의견/주장 접두사는 제거하고 서버가 한 번만 붙이도록 수정했다. 이 수정은 본 게임 종료 후 서버 재시작으로 반영했으며 회귀 테스트를 추가했다. 위 전체 게임 수치는 수정 전 실행 결과다.

AI들이 '근거가 부족하니 기다리겠다'는 발언을 반복했고, 사망자를 투표 대상으로 언급하는 부정확한 자유 발언도 있었다. API와 게임 진행 성공은 추리·대화 품질의 완성을 뜻하지 않는다. opinion 자유 문장은 의미 전체를 검증하지 않는다. 다음 품질 개선은 생존 상태 일관성과 반복 발언 감소, 근거가 있는 의심의 다양성이다. 한 판 결과를 승률 또는 모델 간 우열로 해석하지 않는다.

Python 회귀 테스트 87개 통과. 기존 모의 오류 테스트의 ResourceWarning은 있었으나 실패는 없었다.

[수치 요약](openai-live-summary-v1.json)은 공개 집계다. 전체 게임 상태·발언·LangSmith 원본은 Git에서 제외된 runtime/verification에 로컬 보관한다. API 키와 참가 인증 토큰은 공개하지 않는다.
