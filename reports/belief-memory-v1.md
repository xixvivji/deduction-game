# 개인 판단 기록 전후 확인

2026-10-21, gpt-4.1-mini. 4개의 합성 상황을 조건별 한 번씩 실행했다. 양쪽 모두 MCP·기존 근거 검증을 사용하며, 후 조건만 개인 판단 기록을 사용한다. 이전 의심은 테스트 준비 단계에서 넣었으며 이번 실행에서 모델이 스스로 학습한 기록이 아니다.

| 항목 | 전 | 후 |
|---|---:|---:|
| 보수적 투표/기권 기준 일치 | 3/4 | 3/4 |
| 평균 지연 | 2.337초 | 1.381초 |
| 생성 시도 합계 | 6 | 4 |
| 검증 실패 후 기본 행동 | 1 | 0 |
| 입력 토큰 | 7,636 | 7,192 |
| 출력 토큰 | 377 | 288 |

시민으로 확인된 대상은 양쪽 모두 투표하지 않았다. 전 조건은 검증 실패 후 기본 기권이었고 후 조건은 한 번에 기권했다. 늑대 확인 상황은 양쪽 모두 해당 대상을 선택했다. 모순된 확정 기록 상황은 후 조건에서 기권했다.

다른 참가자에게만 조사 결과가 있는 상황에서는 후 조건이 자기 목격 기록 #2에 근거한 suspected 상태를 유지하며 투표했다. 다른 참가자의 조사 기록을 인용하거나 확정 진영으로 승격하지 않았다. 확정 근거가 없으면 기권한다는 평가 기준에서는 오답이지만 게임 규칙상 허용되는 의심 투표다. 개인 기억이 의심 고착을 만들 수 있다는 한계다.

따라서 전체 정답률 향상은 확인하지 못했다. 지연 차이도 4건 중 기준선 한 건의 재시도 영향이 커 일반화할 수 없다. 충돌 상황은 정상 게임에서 기대되는 사건이 아닌 방어적 테스트다. 반복·holdout·승률·사용자 대화 평가는 수행하지 않았다. 실제 청구 금액은 확인하지 않았다.

[집계](belief-memory-v1.json). 원문·회고는 로컬 runtime/verification/belief-memory-v1.json에만 보관한다.

```sh
.venv/bin/python -m game.evaluate_beliefs
```

이 명령은 .env를 읽고 실제 OpenAI API를 호출한다.

## 실제 웹 게임 통합 확인

5인 게임(자동 입력 사람 1명 + 실제 OpenAI AI 4명)을 끝까지 실행했다. 약 105.56초, 5일 차 늑대 승리로 종료했다. AI 판단 60건, 모델 호출 62회, API 실패와 기본 행동 대체는 각각 0건이었다. 판단 스냅샷 60건의 owner·room_id가 행동과 일치하고 DB에 참가자별 최종 기록 4개가 저장됐다. 종료 전 API에 회고가 노출되지 않는지 확인했다. 전체 개인 발언·회고 원문은 runtime/verification에만 저장했다. 실시간 이동 모드나 장기 승률 평가는 포함하지 않는다. [집계](belief-live-summary-v1.json).

이 실게임에서 판단 상태 변화는 0건이었다. 따라서 기록 전달·저장·종료까지의 통합 경로만 확인한 것이며, 실제 플레이에서 의심 철회를 관측한 결과는 아니다. 의심 생성·철회·확정 충돌·권한 분리는 별도 합성 입력과 회귀 테스트로 검증했다.
