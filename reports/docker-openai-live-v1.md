# Docker 최종 OpenAI 게임 검증

G075 김지원 · 2026-10-22 · 소스 기준 4b8dd0d

Linux ARM64 / Python 3.12.14 Docker 게임 서버에서 gpt-4.1-mini를 사용해 7인 게임 한 판을 실행했다. 사람 1명의 입력은 공개·개인 관측에서 허용된 행동만 REST로 자동 제출했고, 나머지 6명은 실제 AI였다. 기존 밤·토론 모드이며 실시간 이동·공격 모드 전체 검증은 아니다.

- 4일 차 늑대 승리로 정상 종료, 129.2초.
- 사람 행동 9회, 지목 질문 전송 및 답변 확인.
- AI 판단·규칙 적용·DB 저장 76건. 일반 행동 69건, 기본 행동 대체 7건.
- 실제 모델 호출 89회, 통신 실패 0회, 수정·재시도 13회, 재검색 3회.
- 입력 274,784토큰 / 출력 9,036토큰. 청구 금액은 측정하지 않았다.
- MCP stdio 검색 사용. MLflow 전송 76건, 대기 0건, 누락 0건. 실제 저장된 Run의 지표 25개 확인.
- MLflow exporter에 기동 후 누적 전송 실패 1회가 있으나 ready 상태로 복구됐다. 전송 오류가 전혀 없었다는 결과가 아니다.

행동 반영 성공은 발언의 사실 정확도나 추리 성능을 뜻하지 않는다. 7건의 기본 행동 대체와 재시도 비용이 남아 있다. 한 판의 결과로 모델 승률·품질 우열·Docker 속도 향상을 주장하지 않는다. LangSmith는 추적 설정만 확인했으며 이번 실행의 클라우드 trace 수를 별도 대조하지 않았다.
