# 발표용 동일 입력 전후 비교

기존 설정의 OpenAI gpt-4.1-mini로 고정 입력을 각 조건에서 2회 반복했다. 근거 판단 8개 상황(조건별 16회)과 선택이 완전히 고정된 밤 행동 2개(조건별 4회)를 분리했다. 전후 순서는 교대했고 최초 호출도 지연에 포함했다.

전: 권한 필터링된 전체 기록 + 기존 형식/인용 ID 검증.
후: MCP 기억 검색 + 구조화 주장 검증 + 개인 판단 기록 + 고정 행동 호출 생략.
같은 모델과 공통 HTTP 전송 경로를 사용했다. 따라서 여러 변경을 묶은 파이프라인 비교이며, 연결 풀·MCP·RAG 각각의 단독 효과가 아니다.

| 근거 판단 16회 | 전 | 후 |
|---|---:|---:|
| 보수적 투표/기권 기준 일치 | 10/16 | 16/16 |
| 평균 판단 지연 | 1.287초 | 1.317초 |
| 입력 토큰 합계 | 45,328 | 36,420 |
| 출력 토큰 합계 | 746 | 932 |
| 추가 생성 시도 | 0 | 0 |
| 기본 행동 대체 | 0 | 0 |
| 권한 밖 인용 ID | 0 | 0 |

입력 토큰 19.65% 감소, 출력 토큰 24.93% 증가, 평균 지연 약 2.33% 증가다. 실제 청구 금액은 확인하지 않았으며 토큰 감소를 동일 비율의 비용 절감으로 표현하지 않는다. 모든 응답에 사용량 정보가 있었다.

완전히 고정된 밤 행동 4회는 양쪽 모두 기대 행동과 일치했다. 전은 모델 4회·입력 4,334토큰·출력 129토큰, 후는 모델 호출 0회였다. 후의 평균 시간은 소수 셋째 자리 초 단위에서 0.000으로 반올림됐으며 물리적으로 0초라는 뜻이 아니다.

정답은 확정 근거가 있으면 해당 대상 투표, 없으면 기권이라는 보수적 평가 정책이다. 게임에서 허용되는 의심 투표도 오답으로 분류될 수 있다. 고정 보존한 확정 근거가 포함되므로 검색 정밀도나 벡터 Recall@k가 아니다. 별도 holdout·승률·자유 문장 전체의 진실성/정보 누출 평가가 아니다. 실제 웹 토론에서도 자유 발언의 화자·위치 해석 오류는 남아 있다.

[집계 및 건별 지표](release-evaluation-v1.json). 모델 응답·회고 원문은 ignored runtime/verification/release-evaluation-v1.json에만 보관한다.

```sh
.venv/bin/python -m game.evaluate_release --repeats 2
```

이 명령은 .env의 기존 모델과 키로 실제 API를 호출하며 최대 120회의 생성 시도 예산을 적용한다. 이번 실행에서는 총 36회 모델 생성이 있었다. 실습 05/06의 호출 분기, 07/08의 재검색·검증, 10의 사용량 계측, 14의 추적과 평가에 대응한다.
