# AI 근거 파이프라인

## 구현과 실습의 연결

- 에이전트별 역할·개인 관측을 분리하고 공통 LangGraph와 모델 클라이언트를 재사용한다. 서로 다른 전문 업무를 배분하는 Supervisor 구조는 아니며, 같은 게임에 참여하는 독립된 AI 플레이어 구조다.
- FastAPI lifespan에서 MCP 클라이언트와 stdio 서버 프로세스를 한 번 생성하고 종료 시 정리한다. 요청마다 subprocess를 만들지 않는다.
- 메모리 의존성을 주입한다. 웹은 MCPMemory, 단위 테스트와 기존 비교 기준선은 LocalMemory를 사용한다.
- 검색 → 생성 → 구조화 주장 검증 → 조건부 재검색을 LangGraph로 연결한다. 형식 오류는 전체 생성 시도 2회 미만에서 재시도하며, 근거 부족은 재검색 최대 2회, 전체 생성 최대 3회로 제한한다. 실패 시 기본 행동/기권한다.
- LLM 생성, 검색, 검증, 재검색을 LangSmith span으로 추적한다. 게임 화면 진행은 WebSocket이며 토큰 SSE는 구현하지 않았다.

## 실제 MCP 경로와 권한

`game/mcp_memory.py` → stdio MCP → `game/mcp_memory_server.py`의 register_context/search_memory/release_context를 호출한다. `game://rules/evidence` Resource도 읽어 모델 문맥에 전달한다. SDK는 v1 mcp==1.30.0을 고정했다.

서버가 참가자 권한을 적용한 관측을 HMAC 서명하고, MCP 서버가 서명을 검사한 뒤 임시 capability를 발급한다. 검색은 이 capability만 받으며 다른 참가자 ID로 검색하는 인자는 없다. 개인 기록 필터를 서버 측에서 다시 적용하고 검색 후 context를 해제한다. 5분 만료와 최대 64개 context 제한이 있다. MCP 프로세스는 게임 DB를 읽지 않는다. 이 구조는 같은 호스트의 악성 관리자까지 방어하는 보안 격리가 아니며, 외부 공개 MCP 서비스도 아니다.

MCP 실패 시 웹은 방을 일시 중단한다. 검색이 실패했다고 전체 비밀 기록으로 우회하지 않는다. MCP는 서버 통합 코드가 호출하며 LLM이 임의로 도구나 참가자를 선택하는 방식은 아니다.

## RAG와 검증 범위

검색은 한국어 어휘·bigram에 게임 동의어·관련 표현을 확장한 방식이며 임베딩/벡터 DB가 아니다. 거짓말과 진술 모순, 보호와 치료처럼 등록한 표현을 공통 검색 개념으로 연결한다. 이는 검색 관련도이며 같은 사실이라는 판정이 아니다. 원문과 부정 표현은 수정하지 않고 참가자 ID는 글자 조각으로 분해하지 않는다. 자세한 범위와 동일 입력 검색 실측은 [표현 확장 평가](../reports/retrieval-language-v1.md)를 참고한다. 조사·공격 목격 등 중요 기록은 고정 보존하고 재검색은 확장된 문맥을 선택한다. 작은 기록에서는 전체가 전달될 수 있다.

모델이 핵심 주장 종류·대상·값·인용 ID를 구조화해 출력한다. 조사 진영, 검시 역할, 공격 목격, 장소 기록을 코드로 대조한다. 단순 위치 목격을 늑대 확정 근거로 인정하지 않는다. 검증된 발언은 구조화 주장으로부터 문장을 만들어 표시하므로 원래 생성 문장의 추가 단정을 사실로 인증하지 않는다.

- supported_fact: 해당 유형의 사실을 기록이 뒷받침한다.
- grounded_suspicion: 관련 기록이 있는 의심이다. 늑대라는 증명은 아니다.
- opinion: 구조화된 사실 주장 없이 한 의견이다. 자유 문장 의미 전체를 검증하지 않는다.
- game_deception_allowed: 늑대의 게임 전략상 기만을 허용한다. 사실 인증이 아니다.
- abstained: 제한 내 검증을 통과하지 못해 기본 행동으로 대체했다.

종료 후 회고에 상태·재검색 횟수·검색 백엔드를 표시한다. 종료 전에는 개인 audit를 공개하지 않는다. 검증 문장 표준화 때문에 발언의 다양성과 자연스러움이 줄며, 관련 기록만 있는 잘못된 의심이나 기권 때문에 추리 성능이 항상 좋아지는 것은 아니다. 직접 질문에 대한 자유로운 답변 품질도 추가 평가가 필요하다.

## LangSmith

기존 실행 명령에 LANGSMITH_TRACING=true, LANGSMITH_API_KEY, LANGSMITH_PROJECT를 설정하면 추적한다. ./run_web.sh 실행 시 루트 .env를 읽으며 기존 환경변수가 우선한다. 키는 Git에 넣지 않는다. 기본은 추적 비활성이다. 추적에는 개인 역할·관측·발언이 포함될 수 있다.

SDK의 create_run/update_run 모의 테스트에 더해, 2026-10-21 실제 계정에서 7인 게임의 AI 판단 72건이 모두 완료 상태로 저장된 것을 확인했다. 샘플 하위 span의 room_id를 대조해 MCP 검색·모델 생성·근거 검증이 해당 게임에 연결됐음을 확인했다.

## 검증 및 남은 과제

실제 stdio MCP 왕복, 참가자 간 기억 분리, 서명 위조 거부, 폐기된 context 거부, 재검색 성공/상한, 사실 발언 표준화, 늑대 기만 구분, 웹 lifespan 연결을 테스트한다. 실제 로컬 모델의 짝지은 결과는 reports/evidence-pipeline-v1.md를 참고한다.

다음 과제는 별도의 미사용 평가 세트, 공격 목격 기반 투표 실패 분석, 장기 게임 승률·대화 품질 평가다. Multi-Agent/MCP/RAG/의존성 주입/테스트의 구현 근거는 있지만 발표 자료 작성과 더 넓은 품질 평가는 별도다.

## 자유 문장 우회와 시점 보완

`claim_type=none`이어도 일반적인 한국어 게임 사실 단정(공격했다, 늑대입니다, 특정 장소에 있었다 등)이 탐지되면 `untyped_fact`로 거부한다. 같은 문장에 질문이나 부정문이 섞여 있어도 다른 단정을 무조건 면제하지 않는다. LLM에 사실 구조화 또는 확인 질문으로 고치라는 피드백을 주며, 이 경로의 수정은 최대 1회다. 근거 재검색·토론 품질 수정 횟수와 분리하며 모든 경로의 전체 생성 상한은 3회다. 실패하면 안전한 질문 또는 기본 행동으로 대체한다.

이는 정규식 기반의 제한된 한국어 표현 검사다. 모든 자연어 사실을 이해하거나 우회 표현을 완전히 막지 못한다. 사실을 인용하거나 다른 사람의 말을 전달한 문장도 보수적으로 수정될 수 있다. 늑대의 자유 발언은 게임상 허용된 기만으로 표시하며 사실 인증으로 취급하지 않는다. 검증 LLM을 추가하지 않아 검사 자체의 API 호출은 없지만 수정 생성 때문에 비용은 늘 수 있다.

`visited`와 `witnessed_attack`의 공개 문장은 주장을 실제로 뒷받침하는 인용 기록의 일차·탐색 초를 사용한다. 다른 인용의 시각이나 모델이 쓴 시각을 가져오지 않는다. 과거 위치를 현재 위치·전체 동선으로 해석하지 않도록 문장을 명시한다. 검시 역할이 누락된 기록은 시민 확인에 쓰지 않는다.
