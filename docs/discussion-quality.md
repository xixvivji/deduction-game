# AI 토론 품질 개선

## 동작

웹의 실제 모델은 verified 근거 파이프라인에 토론 품질 검사를 추가한다. 공개 발언 단계에만 적용하며, 투표/능력/늑대 비밀 협의는 기존 흐름을 유지한다. 고정 문장을 내는 규칙 봇은 품질 재작성 대상에서 제외한다.

1. 권한 적용된 관측으로 현재 생존자·사망자, 최근 본인 공개 발언 3건과 최근 공개 발언 3건을 만든다. 별도 비밀 정보나 다른 사람의 개인 기억을 사용하지 않는다.
2. 추가 문맥에 포함한 기록은 검색 결과에도 합쳐 유효한 인용으로 사용할 수 있게 한다.
3. 기존 근거 검증 후 실제 표시할 발언을 검사한다. 사망자에 대한 직접 투표/추방 제안, 시점을 한정하지 않은 현재 위치 단정, 최근 자기 발언과의 유사도 0.88 이상 반복, 반복적인 판단 보류를 확인한다.
4. 문제를 발견하면 구체적인 수정 지침과 함께 한 번만 다시 생성한다. 이는 재검색과 구분하며 quality_retries/quality_history로 회고에 저장한다. 전체 생성 시도는 기존과 합쳐 최대 3회다.
5. 다시 실패하면 생존자에게 기록을 확인하는 질문으로 대체한다. 직접 지목 질문에 답할 수 없으면 답변을 만들지 못했다는 문장으로 대체한다. 새로운 사실은 만들어내지 않는다. 이 공개 질문은 별도의 답변 차례를 자동으로 만들지 않는다.

## 범위와 한계

한국어 규칙·정규식·문자열 유사도 검사이며 일반적인 의미 이해 모델이나 모든 허위 주장 검증기가 아니다. 표현에 따라 오탐/누락이 가능하다. 사망자의 과거 행동/검시 결과 언급, 부정문, 과거 발언 인용은 허용한다. 지목 질문은 재확인을 요구할 수 있으므로 단순 반복 검사에서 제외하되 생존/시점 검사는 유지한다.

같은 근거를 강조할 필요가 있어도 중복으로 판정될 수 있다. 질문을 포함한 판단 보류나 다르게 표현한 반복은 놓칠 수 있다. 추가 문맥 때문에 토큰이 늘며, 재작성 시 지연·비용이 추가된다. 이전 목격의 일차 자체가 정확한지는 이 텍스트 규칙만으로 완전히 확인하지 않는다. 늑대의 기만을 제거하지 않으며 근거 인증과 게임 전략은 기존 정책대로 구분한다.

이번 범위는 사망자/시점 혼동과 발언 반복 개선이다. 참가자별 장기 의심 점수, 질문 의미 적합성 평가, 자동 지목 질문 턴 생성은 구현하지 않았다.

## 검증

사망자 투표와 부정·과거·인용 문장 구분, 시점 한정, 발언 반복, 재확인 질문 예외, 재작성 성공/상한, 최근 발언 인용 가능 여부와 권한을 회귀 테스트한다. 실제 OpenAI 비교는 [평가 결과](../reports/discussion-quality-v1.md)를 참고한다.

```sh
.venv/bin/python -m unittest discover -s tests -q
.venv/bin/python -m game.evaluate_discussion --repeats 2
```

평가 도구는 .env를 읽으며 실제 OpenAI 호출 비용이 발생한다. 응답·회고 원문은 Git에서 제외된 runtime/verification에, 집계만 reports에 기록한다. 두 조건 모두 MCP와 기존 근거 검증을 사용하고 토론 품질 옵션만 전환한다.
