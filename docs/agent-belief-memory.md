# AI 개인 판단 기록

## 무엇을 기억하는가

참가자별로 대상의 상태(unknown / suspected / confirmed_wolf / confirmed_village / conflicted), 근거 이벤트 ID, 갱신 일차, 현재 관측의 생존 여부를 저장한다. 확인된 진영은 모델의 자신감 점수가 아니라 조사·검시·공격 목격 기록을 코드로 대조한 결과다. 확률이나 의심 점수는 부여하지 않는다.

- unknown: 진영 판단 근거 없음. 위치 목격이나 다른 사람의 주장만으로 확정하지 않는다.
- suspected: AI가 유효한 관련 기록을 근거로 구조화된 의심을 선택한 상태. 사실 인증이 아니다.
- confirmed_wolf / confirmed_village: 해당 참가자에게 허용된 서버 사실이 진영을 뒷받침한다.
- conflicted: 서버 사실끼리 충돌하는 방어적 상황. 임의로 최신 기록만 선택하지 않고 확정을 보류한다. 정상 게임의 조사 결과는 역할이 고정되어 있으므로 이런 충돌은 주로 합성 테스트 대상이다.

새 시민 조사 결과는 이전 의심보다 우선한다. 검증된 시민 확인 발언에서 해당 차례에 의심을 철회했다면 철회 문장을 덧붙인다. 기존 의심에 매달려 확인된 시민을 늑대로 단정하거나 투표하려 하면 근거 검증 실패로 처리한다. 자유 문장 전체의 의미까지 검사하는 것은 아니다.

## 흐름과 저장

1. AI 차례의 권한 적용된 전체 관측과 그 참가자의 이전 판단 기록으로 상태를 갱신한다.
2. MCP 검색 후 판단 기록과 관련 근거를 모델 문맥에 포함한다. 기존 의심의 근거도 유효한 인용 ID로 사용할 수 있도록 검색 결과에 보존한다.
3. 모델의 구조화 주장을 기존 근거 검사와 개인 판단 기록에 대조한다. 기존 제한 재검색 흐름을 재사용하며 전체 생성은 최대 3회다.
4. 허용된 의심만 개인 기록에 저장한다. 늑대의 공개 기만은 개인 의심으로 승격하지 않는다. 늑대 자신의 역할·동료 정보는 기존 self 관측에 있고, 개인 기록이 동료 정보 전체를 새로 추론하는 것은 아니다.
5. 게임 행동 성공 후 room.data의 beliefs[actor] 및 해당 행동 audit에 함께 저장한다. 서버 재시작 시 기존 SQLite 방 상태와 함께 복원한다. 이전 저장 방은 기록이 없으면 빈 상태에서 시작한다.

상태 변화 이력은 최근 20건으로 제한한다. 현재 대상별 기록은 유지한다. 동일 상태라도 새로운 근거가 추가되면 갱신 일차를 바꾼다. 판단 기록은 해당 AI가 행동할 때 갱신되므로 사망한 AI의 마지막 기록은 과거 시점의 스냅샷이다.

## 정보 경계와 화면

기록은 room_id와 owner가 일치할 때만 재사용한다. 다른 참가자의 조사·목격은 다시 필터링한다. 다른 AI의 전체 판단 목록을 모델에게 전달하지 않는다. 사람용 API에는 게임 종료 전 beliefs나 audit를 넣지 않는다. 종료 후 AI 선택 회고에서 개인 판단 변화와 근거 ID를 펼쳐 볼 수 있고 JSON에는 해당 차례의 전체 판단 스냅샷이 포함된다.

LangSmith 추적을 켠 경우 이러한 개인 게임 기록이 추적 서비스에 포함될 수 있다. Git에는 키와 원본 게임/추적 기록을 올리지 않고 평가 집계만 올린다.

## 한계와 비용

개인 기록은 허용된 사건과 구조화된 모델 의심을 정리한 상태다. 사람처럼 모든 발언의 의미를 추론하거나 상대의 거짓말을 자동 판정하는 장기 기억은 아니다. 의심을 지속시키므로 근거가 약한 대상에 계속 투표하는 고착도 가능하다. 근거 갱신은 코드가 처리하며, 어떤 공개 발언을 할지는 LLM이 결정한다.

추가 LLM 호출로 기록을 요약하지 않는다. 대신 입력 문맥과 저장량이 늘고, 이전 의심 근거를 보존하므로 검색 문맥이 커질 수 있다. 현재 각 AI 차례에 전체 개인 이벤트를 다시 검사하므로 이벤트 수가 커지면 증분 갱신이 필요하다. 판단 스냅샷을 행동별 회고에 저장하므로 기록 중복도 있다.

실측은 [소규모 전후 평가](../reports/belief-memory-v1.md)를 참고한다. 정보 분리, 갱신·철회, 충돌, 늑대 기만 분리, 재검색 상한, 실제 서버 저장 경로와 재시작 복구를 테스트한다.
