# 화면 그래픽 정리

2026-10-22 · 기능 확장 이후 표현과 가독성만 정리했다.

- 지도: 돌길 패턴, 기와 지붕·창문, 가로등, 숲과 물가 표현. 실제 통행 영역은 서버가 보내는 roads/courts/buildings를 그대로 그린다. 나무 장식은 통행·건물 영역을 피해 컴포넌트 생성 시 한 번 계산한다.
- 시야: 서버의 115 범위를 유지하고 안쪽 경계만 부드럽게 표현한다. 다른 참가자는 서버에서 전달된 현재 위치만 사용한다. 안내도에는 본인만 표시한다.
- 캐릭터: 역할과 무관한 ID별 옷 색상, 얼굴·망토·신발과 이름 길이에 맞는 이름표. 기존 좌표 보간을 유지한다.
- 화면: 달빛과 따뜻한 금색 계열, 입장 제목·카드·버튼·기록의 간격과 대비 조정. 넓은 화면의 지도 여백을 줄이고 390px 모바일에서도 가로 넘침을 확인했다.
- 움직임 줄이기와 방향 버튼 유지. 탐색 종료와 WebSocket 갱신 사이의 정상적인 409 이동 거절은 알림에서 제외한다. 다른 오류는 기존대로 표시한다.

브라우저에서 11인 배치, 탐색 지도, 방향 버튼 이동, 단계 전환, 움직임 줄이기, 모바일 390×844를 점검했다. 기존 이동 보간·시야 밖 인물 제거 JavaScript 테스트 4개 통과. 화면 검증은 별도 규칙봇 서버에서 수행했으며 실제 AI 성능 평가와 구분한다.
