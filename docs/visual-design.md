# 화면 그래픽 정리

2026-10-22 · 기능 확장 이후 표현과 가독성만 정리했다.

- 지도: 돌길 패턴, 기와 지붕·창문, 가로등, 숲과 물가 표현. 실제 통행 영역은 서버가 보내는 roads/courts/buildings를 그대로 그린다. 나무 장식은 통행·건물 영역을 피해 컴포넌트 생성 시 한 번 계산한다.
- 시야: 서버의 115 범위를 유지하고 안쪽 경계만 부드럽게 표현한다. 다른 참가자는 서버에서 전달된 현재 위치만 사용한다. 안내도에는 본인만 표시한다.
- 캐릭터: 역할과 무관한 ID별 옷 색상, 얼굴·망토·신발과 이름 길이에 맞는 이름표. 기존 좌표 보간을 유지한다.
- 화면: 달빛과 따뜻한 금색 계열, 입장 제목·카드·버튼·기록의 간격과 대비 조정. 넓은 화면의 지도 여백을 줄이고 390px 모바일에서도 가로 넘침을 확인했다.
- 움직임 줄이기와 방향 버튼 유지. 탐색 종료와 WebSocket 갱신 사이의 정상적인 409 이동 거절은 알림에서 제외한다. 다른 오류는 기존대로 표시한다.

브라우저에서 11인 배치, 탐색 지도, 방향 버튼 이동, 단계 전환, 움직임 줄이기, 모바일 390×844를 점검했다. 기존 이동 보간·시야 밖 인물 제거 JavaScript 테스트 4개 통과. 화면 검증은 별도 규칙봇 서버에서 수행했으며 실제 AI 성능 평가와 구분한다.

## 건물 내부와 출입 (2026-10-22)

사용자 요청에 따라 창고, 진료소, 여관, 종탑에 들어갈 수 있는 별도 실내 공간을 추가했다. 문 앞 38px 이내에서 E키 또는 버튼으로 출입한다. 건물별 상자·침대·탁자·종과 바닥을 직접 SVG로 그렸다. 실내의 벽과 가구는 서버 충돌 및 시선 판정에 함께 사용한다.

- `game/exploration.py`: 참가자별 `spaces`와 `space_epochs`, 방별 충돌 지도, 출입 검증, 시야·공격·신고·목격의 같은 공간 검사. AI 순찰은 공개 지도와 출입문만 이용하며 숨은 거주자 위치를 탐색하지 않는다. 실내 종료 장소는 기존 게임의 건물 이름으로 기록한다.
- `game/server.py`: 인증된 `/door` 요청에서 날짜·공간 세대를 검사한다. 출입 후 기존 이동 입력을 지우고 공간 세대를 증가시켜 지연 요청과 출입 재전송을 거부한다. 기존 공간의 이동·현장 행동도 거부한다. 공간과 시체 상태는 기존 SQLite 스냅샷에 저장된다.
- `frontend/assets/exploration.js`: 현재 공간만 렌더링하며 실내에서는 외부 지도·안내도를 제거한다. 전환 시 보간을 초기화하고 화면 실제 종횡비에 맞춰 카메라를 계산한다. 출입구의 캐릭터가 화면 아래로 잘리던 문제도 수정했다.

실내외 숨김은 CSS 처리만이 아니다. 서버 응답에 다른 공간의 플레이어·시체 좌표나 다른 방의 내부 도형을 포함하지 않는다. 사람과 현장 AI의 관측 판정이 같다. 과거의 정상적인 목격 기억은 유지되며 현재 위치를 보장하는 정보로 취급하지 않는다.

참고 자료: [덕몽어스 공식 소개](https://store.steampowered.com/app/1568590/Goose_Goose_Duck/), [공식 Goosechapel 맵 업데이트](https://store.steampowered.com/news/app/1568590/view/3046115130600887739). 공식 소개의 다양한 탐색 환경, 맵 업데이트의 출입문·시야 제한 요소를 참고했다. 실내외를 완전히 분리하는 규칙은 이번 프로젝트의 요청에 맞춘 설계이며, 덕몽어스의 모든 맵이 동일한 규칙이라는 뜻은 아니다. 원작 이미지나 코드는 사용하지 않았다.

검증: Python 전체 221개, JS 6개 통과. 신규 검사는 실내외 좌표 일치 상황의 정보 분리, 다른 방 사이의 공격·신고·목격 차단, 문 거리·권한·공간 세대 검증, WebSocket 응답 분리, 저장 및 복구, 벽·가구 충돌, AI 출입을 포함한다. 11 AI의 180초 가상 시간 시뮬레이션에서 네 실내와 실외 방문을 확인했다. 브라우저 화면은 별도 demo 서버에서 시간을 늘리고 시작 위치를 지정한 조작 검증용이며 실제 AI 성능 평가나 일반 게임 시간의 증거로 사용하지 않는다.

화면 검증: 실제 데모 서버에서 버튼 입장, E키 퇴장, 실내 방향키 이동, 외부 안내도 제거 및 복원을 확인했다. 390×844 iframe에 같은 Vue 컴포넌트를 렌더링해 모바일 가로 넘침 없음(390px), 실내 도형 1개·외부 도형 0개를 확인했다. 모바일 검사는 읽기 전용 배치 검사이며 모바일 기기의 실제 터치 검증과는 구분한다. 개발자 콘솔 오류 없음.
