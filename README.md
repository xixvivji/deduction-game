# 추리 게임 — 프로젝트명 미정

사람과 AI가 시민 또는 늑대가 되어 낮에는 토론·투표하고 밤에는 장소를 선택해 행동하는 턴제 사회적 추리 게임.

현재 규칙 엔진과 자동 진행 데모를 구현했습니다. Ollama를 연결한 터미널 플레이를 지원합니다. 웹 화면·네트워크 멀티는 아직 없습니다. GuardLab과 별개 프로젝트입니다.

- 첫 버전: 사람 1명 + AI 6명 (기본 7인, 5인 선택 가능)
- 후속 버전: 여러 사람이 같은 방에 참가하고 남은 자리를 AI로 구성
- 설계: [게임 및 멀티플레이 구조](docs/design.md)
- Git 관리: Git Flow, feature/* 사용, 타입 + 한글 커밋 메시지

저장소: https://github.com/xixvivji/deduction-game

## 실행 및 검증

Python 3.10 이상, 외부 패키지 없이 실행합니다.

```sh
python3 -m unittest discover -s tests -v
python3 -m game.demo
```

데모는 모든 참가자의 행동을 규칙 기반 봇으로 대신합니다. 실제 모델과 플레이하려면 아래 명령을 사용합니다.

- `game/engine.py`: 역할, 명령 검증, 단계 전환, 정보 공개 범위
- `game/demo.py`: 최대 라운드까지 자동 진행하는 실행 예제
- `tests/test_engine.py`: 권한, 상태, 정보 분리, 종료 조건 테스트

현재 엔진은 단일 프로세스에서 순차 호출해야 합니다. 인증, 방 단위 명령 큐, DB 저장과 재접속은 API 단계에서 구현해야 합니다. `advance()`는 서버 진행자 전용입니다.

## 실제 AI와 플레이

별도 터미널에서 `ollama serve`를 실행하고 설치된 모델을 지정합니다. 기본값은 로컬에서 확인한 `qwen3:4b-instruct`입니다. 모델 다운로드는 자동으로 수행하지 않습니다.

```sh
python3 -m game.play
python3 -m game.play --players 5 --model qwen3:0.6b
```

시작 시 내 역할이 표시됩니다. 발언은 텍스트, 투표/능력 대상은 p0~p6 ID, 장소는 광장/창고/숲길로 입력합니다. 대상 입력에서 Enter는 기권/능력 미사용입니다. 사망 후에는 공개 진행을 관전합니다. Ctrl+C로 종료할 수 있습니다.

- 7인: 늑대 2, 조사자 1, 시민 4. 5인: 늑대 1, 조사자 1, 시민 3.
- 늑대는 동료를 알며 동료를 공격할 수 없습니다. 생존 늑대 모두 같은 대상을 선택해야 한 명이 공격받습니다. 불일치/기권 시 공격하지 않습니다. 늑대 비밀 대화는 아직 없어서 합의가 어렵다는 한계가 있습니다.
- AI 호출은 순차 실행합니다. 인원이 많으면 대기 시간이 길어집니다. 발언은 하루 2회입니다.
- 모델 오류는 1회 재시도 후 기본 행동으로 대체하고 터미널에 표시합니다.
- 기억 검색은 아직 없고 허용된 기록 전체를 전달합니다. 긴 게임은 모델의 컨텍스트 한도와 지연 문제가 있으므로 후속 RAG/요약 비교 대상입니다.
- `game/ai.py`: 교체 가능한 모델 클라이언트, 구조화 출력, 허용 행동, 재시도
- `game/play.py`: 터미널 입력과 게임 루프

짧은 실제 모델 통합 테스트(모든 참가자가 AI, 첫날 종료):

```sh
python3 -m game.play --auto --max-days 1 --seed 42 --metrics /tmp/game-metrics.json
```

통계에는 호출별 시간·실제 토큰 수와 재시도/기본 행동 여부를 기록합니다. 짧은 테스트는 전체 게임 재미나 추론 품질의 검증이 아닙니다. 일반 플레이에서는 역할이 예측되지 않도록 seed를 생략합니다.

### 현재 검증 범위와 한계

단위 테스트 17개로 기존 5인 규칙, 7인 공동 공격, 정보 분리, 모델 실패 시 기본 행동, 사용자 입력 재시도를 확인했습니다. 실제 Ollama의 7인 1일 자동 진행 및 최종 코드의 2일 자동 진행을 종료까지 확인했습니다. 0.6B 모델은 발언 반복이 많았고 4B 모델에서도 잘못된 추론과 자발적인 역할 공개가 관찰되어 역할별 지시를 보완했습니다. 보완 후 늑대 발언 두 건에서 정체 공개가 없었지만, 비밀 유지나 추리 품질을 보장하는 평가 결과는 아닙니다.

아직 늑대 비밀 협의, 플레이 저장/재개, 웹 화면, 네트워크 멀티, LangGraph/RAG/MCP 연결은 없습니다. 현재 AI 모듈은 순차 제어 구조이며, 이후 그래프 적용 전 비교 기준으로도 사용할 수 있습니다.
