# 추리 게임 — 프로젝트명 미정

사람과 AI가 시민 또는 늑대가 되어 낮에는 토론·투표하고 밤에는 장소를 선택해 행동하는 턴제 사회적 추리 게임.

현재 규칙 엔진과 자동 진행 데모를 구현했습니다. 실제 AI 호출·웹 화면·네트워크 멀티는 아직 없습니다. GuardLab과 별개 프로젝트입니다.

- 첫 버전: 사람 1명 + AI 4명
- 후속 버전: 여러 사람이 같은 방에 참가하고 남은 자리를 AI로 구성
- 설계: [게임 및 멀티플레이 구조](docs/design.md)
- Git 관리: Git Flow, codex 접두사 없이 feature/* 사용, 타입 + 한글 커밋 메시지

새 원격 저장소는 아직 생성하지 않았습니다.

## 실행 및 검증

Python 3.10 이상, 외부 패키지 없이 실행합니다.

```sh
python3 -m unittest discover -s tests -v
python3 -m game.demo
```

데모는 모든 참가자의 행동을 규칙 기반 봇으로 대신합니다. 사용자 입력 또는 실제 AI를 연결한 플레이 화면은 다음 단계입니다.

- `game/engine.py`: 역할, 명령 검증, 단계 전환, 정보 공개 범위
- `game/demo.py`: 최대 라운드까지 자동 진행하는 실행 예제
- `tests/test_engine.py`: 권한, 상태, 정보 분리, 종료 조건 테스트

현재 엔진은 단일 프로세스에서 순차 호출해야 합니다. 인증, 방 단위 명령 큐, DB 저장과 재접속은 API 단계에서 구현해야 합니다. `advance()`는 서버 진행자 전용입니다.
